# Hypixel Custom Recipe Items

A server-side Fabric mod for Minecraft Java 26.2. It registers the custom items used by the Hypixel-style datapack.

## Items

- hypixel:old_dragon_fragment
- hypixel:protector_dragon_fragment
- hypixel:wise_dragon_fragment
- hypixel:young_dragon_fragment
- hypixel:strong_dragon_fragment
- hypixel:unstable_dragon_fragment
- hypixel:superior_dragon_fragment
- hypixel:holy_dragon_fragment
- hypixel:necron_core

The mod registers item IDs only. Crafting recipes belong in the datapack.

## Server installation

Install these on the dedicated server:
1. Fabric Loader for Minecraft 26.2
2. Fabric API for Minecraft 26.2
3. Polymer Bundled 0.17.5+26.2
4. This mod jar

Players joining the server do not need this mod installed. Polymer represents the custom items as vanilla items for vanilla clients. The icons currently use vanilla fallback item appearances.

## Commands

Use /give @s hypixel:old_dragon_fragment (replace the ID with any item listed above) to test an item.
